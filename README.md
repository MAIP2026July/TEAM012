# Team Name

### Working Title
AI Product for Vendor Pulse

A receiving copilot for grocery and supercenter chains: it predicts when small DSD vendors (no ASN) will really arrive, how likely they are to be late or reschedule, and how reliable they have been, so the dock is staffed when the truck arrives.
